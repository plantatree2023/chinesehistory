# 数据集说明

本目录存放时间轴的数据集。每个数据集是一个 JSON 文件，包含该国的**时期划分**（`eras`）和**历史事件**（`events`）。
网站、本地服务器（`server.js`）、维基导入脚本（`tools/wiki-import.js`）和测试都读写这里的文件。

## 文件命名

```
data/<国家>_<语言>.json
```

| 部分 | 规则 | 例 |
|---|---|---|
| 国家 | ISO 3166-1 两位小写字母代码 | `cn` 中国、`jp` 日本 |
| 语言 | ISO 639 两到三位小写字母代码，可附加文字变体（`-` 后 2–8 位字母或数字） | `zh`、`en`、`zh-Hant` |

例：`cn_zh.json`（中国 · 中文，默认数据集）、`cn_zh-v0.json`（中国 · 中文旧版，104 个事件）、`jp_ja.json`（日本 · 日文）、`cn_en.json`（中国 · 英文）。

- 网站通过网址参数选择数据集：`?data=jp_ja`；不带参数时使用 `cn_zh`。
- 界面语言由文件名中的语言部分决定（`cn_en` → 英文界面），对应 `js/i18n/<语言>.js`；没有该语言的界面文件时显示中文界面。
- 翻译版数据集（如 `cn_en.json`）由同一国家的中文数据集翻译而来：事件 `id`、`year`、`majorScore`、图片（`src`、`w`、`h`）、参考链接网址、时期的起止年份和颜色、类型的 `key` 和颜色与中文版相同，文字（时期名、类型名、事件文字、图片标题、链接标题）翻译；`type` 与 `transition` 用翻译后的名称。中文版的修改不会自动同步；`tests/i18n.spec.js` 检查翻译版的每个事件都在中文版中（id、年份相同）、时期和类型对应、没有中文。
- 维基导入脚本根据文件名决定查询哪种语言的维基百科（`cn_zh.json` → 中文维基，简体）。
- 名称不符合上述格式的文件不会被网站加载，服务器也拒绝写入。
- 部署时 `tools/build-site.js` 为每个数据集的每个事件生成静态页（供搜索引擎收录和分享）并写入 `sitemap.xml`：默认数据集在 `e/<事件id>.html`，其他数据集在 `e/<数据集>/<事件id>.html`。新增 / 修改事件或新增数据集后推送即可，页面会在部署时自动更新，不需要改代码。页面用到 `id`、`year`、`title`、`date`、`short`、`detail`、`images`、`sources`、`transition` 和 `eras`；缺少 `id` 或 `title` 的事件不生成页面，其余字段缺少时省略对应部分。

## 整体结构

```json
{
  "id": "cn_zh",
  "country": "cn",
  "language": "zh",
  "description": "可以拖动浏览的中国历史时间轴：按朝代排列重大历史事件，点开查看详细说明和图片。",
  "eras": [ { "name": "唐", "start": 618, "end": 907, "...": "..." } ],
  "types": [ { "key": "war", "name": "战争", "color": "#5f4b8b" } ],
  "music": { "src": "audio/bgm-cn.mp3", "volume": 0.2, "title": "", "credit": "" },
  "texture": { "src": "textures/cn-xuanzhi.svg", "size": 240, "opacity": 0.12 },
  "events": [ { "id": "e052", "year": 755, "title": "安史之乱", "...": "..." } ]
}
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `id` | 字符串 | 是 | 数据集名称，**必须与文件名（去掉 `.json`）完全一致**，例如 `cn_zh`。服务器保存时会核对。 |
| `country` | 字符串 | 是 | 国家代码，与文件名中的国家部分一致，例如 `cn`。 |
| `language` | 字符串 | 是 | 语言代码，与文件名中的语言部分一致，例如 `zh`。 |
| `description` | 字符串 | 否 | 网站简介，用作网页的 `description`、`og:description`、`twitter:description`（搜索结果和分享卡片中显示），不超过 200 字。用该数据集的语言、写明国家；**不写具体数字**（事件数、年份会随数据变化）。默认数据集的简介在部署时写进首页，其他数据集在网页加载后替换；没有时使用 `index.html` 中的通用文字。 |
| `eras` | 数组 | 是 | 时期划分，见下文。 |
| `types` | 数组 | 否 | 事件类型列表，见下文。 |
| `music` | 对象 | 否 | 背景音乐，见下文。没有时网页不播放音乐、也不显示音乐按钮。 |
| `texture` | 对象 | 否 | 时间轴的背景纹理，见下文。没有时不显示纹理。 |
| `events` | 数组 | 是 | 历史事件，见下文。 |

## 时期（`eras`）

时期决定时间轴上的朝代色带、悬浮 / 点击时间轴时的时期提示、顶栏标题后的当前时期名和下沿色条、底部进度条的分段，以及侧栏“朝代 / 时期”下拉筛选的选项（只列出有事件的时期，带该时期的颜色）。时期名也是事件 `transition` 字段引用的名称，修改时期名时要同步修改。

```json
{ "name": "唐", "start": 618, "end": 907, "color": "#c0892f", "range": "618年—907年", "desc": "国力强盛、文化繁荣的开放王朝" }
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `name` | 字符串 | 是 | 时期名称，显示在色带上、时期提示、顶栏和进度条标签中。 |
| `start` | 整数 | 是 | 起始年份（公元纪年，公元前为负数），用于判断某一年属于哪个时期。 |
| `end` | 整数或 `null` | 是 | 结束年份，用于绘制色带的右端。**`null` 表示延续至今**：色带一直画到时间轴末端（“今天”刻度）。 |
| `color` | 字符串 | 是 | 十六进制颜色（如 `#c0892f`），用于色带、进度条色段、顶栏下沿色条和标题中的时期名。 |
| `range` | 字符串 | 是 | 显示用的起止年代文字，出现在时期提示中，例如 `约前2070年—前1600年`、`1949年至今`。可以与 `start` / `end` 不完全一致（例如史学上有争议的年代写“约”）。 |
| `desc` | 字符串 | 是 | 一句话简介，出现在时期提示中。 |

规则：

- 按 `start` 从早到晚排列。某一年属于**起始年份不晚于它的最后一个时期**，因此时期之间不要有空档；重叠时后面的时期优先。
- 第一个时期的 `start` 应早于最早的事件。
- 顶栏标题使用书法字体，字体文件只包含标题和现有时期名用到的字；新时期名若含其他字，会回退为宋体显示（见仓库根目录 README）。

## 背景音乐（`music`）

每个数据集（国家 / 语言）可以有自己的背景音乐。音频文件放在仓库的 `audio/` 目录，网站只从本地加载。网页在开始加载时于后台下载音乐（不推迟页面加载完成），下载完成后自动播放（浏览器不允许时等访问者第一次操作）；访问者关闭了音乐时不下载。

```json
{ "src": "audio/bgm-cn.mp3", "volume": 0.2, "title": "曲名", "credit": "作者 / 授权说明" }
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `src` | 字符串 | 是 | 音频文件路径，**只能是 `audio/<文件名>`**，格式为 MP3、OGG 或 M4A。建议 128 kbps 左右、3 MB 以内（测试会检查），循环播放。 |
| `volume` | 数字 | 否 | 音量，0–1，缺省为 0.2（较小，作为背景）。 |
| `title` / `credit` | 字符串 | 否 | 曲名和作者 / 授权说明，供记录版权来源（网页暂不显示）。 |

浏览器不允许网页在访问者操作之前自动发声，所以音乐在访问者第一次点击、按键或触摸页面时开始；右上角的喇叭按钮可以关闭（会记住选择）。

## 背景纹理（`texture`）

每个数据集（国家 / 语言）可以有自己的清淡背景纹理，铺在时间轴区域后面，不随时间轴移动。纹理文件放在仓库的 `textures/` 目录，网站只从本地加载。

```json
{ "src": "textures/cn-xuanzhi.svg", "size": 240, "opacity": 0.12 }
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `src` | 字符串 | 是 | 纹理图片路径，**只能是 `textures/<文件名>`**，格式为 SVG、PNG 或 WebP，内容是可以无缝平铺的单元。 |
| `size` | 数字 | 否 | 平铺单元的显示宽度（像素，8–2000），缺省为图片本身的大小。 |
| `opacity` | 数字 | 否 | 不透明度，0–0.3，缺省为 0.06。纹理应当清淡，不影响阅读。 |

纹理图片只用作**形状**（按透明度取用，图片本身的颜色不起作用）：画在透明背景上的线条或图形即可。颜色由网页配色决定（`css/style.css` 中的 `--texture-ink`），浅色和深色模式各自适配。现有的中国纹理（`textures/cn-*.svg`）：回纹 `huiwen`、祥云 `xiangyun`、冰裂纹 `binglie`、海水纹 `haishui`、古钱纹 `qianwen`、宣纸纤维 `xuanzhi`。其他国家建议命名为 `<国家>-<名称>.svg`。

## 事件类型（`types`）

事件类型的列表，决定侧栏“事件类型”下拉列表中选项的顺序和颜色，以及列表、详情中类型标签的颜色。列表中没有事件的类型不显示在下拉列表中。

```json
{ "key": "war", "name": "战争", "color": "#5f4b8b" }
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `key` | 字符串 | 建议 | 类型的通用标识（小写英文），与语言无关。维基导入脚本推断出类型后，用 `key` 找到本数据集中的类型名。脚本认识的 key：`prehistory` 史前、`politics` 政治、`war` 战争、`culture` 文化、`science` 科技、`economy` 经济、`foreign` 对外交流、`society` 社会。 |
| `name` | 字符串 | 是 | 显示的类型名，也是事件 `type` 字段使用的值；不能重复。修改类型名时要同步修改事件中的 `type`。 |
| `color` | 字符串 | 否 | 十六进制颜色（如 `#5f4b8b`），用作类型标签的**文字和描边颜色**（标签不填充、直角，与朝代 / 时期的实心圆角色块在形状上区分；类型颜色可以与朝代颜色相近）。与白色的对比度应不低于 4.5（测试会检查）；深色模式下网页会自动调亮。 |

## 事件（`events`）

每个事件对应时间轴上的一张卡片。文件中的事件按 `year` 排序（网站和导入脚本写入时会自动排序），便于查看 git diff。

```json
{
  "id": "e052",
  "year": 755,
  "date": "755年",
  "title": "安史之乱",
  "short": "节度使安禄山与史思明起兵叛乱，历时七年多，唐朝由此由盛转衰。",
  "detail": "安史之乱（755年12月16日－763年2月17日）是中国唐中期爆发的一场大规模内战……",
  "images": [
    { "src": "images/1f0e3c9a7b2d4e5f.jpg", "w": 500, "h": 375, "caption": "安禄山像" }
  ],
  "sources": [
    { "url": "https://zh.wikipedia.org/wiki/%E5%AE%89%E5%8F%B2%E4%B9%8B%E4%BA%82" },
    { "url": "https://example.org/jiutangshu", "title": "《旧唐书·安禄山传》" }
  ],
  "type": "战争",
  "majorScore": 7
}
```

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `id` | 字符串 | 是 | 事件的唯一标识，**数据集内不能重复**。初始数据为 `e001`–`e100`；导入脚本新增时取下一个编号（`e101`……）；在网页中新增的事件使用自动生成的随机标识。修改事件时不要改动。 |
| `year` | 整数 | 是 | 事件年份，公元纪年，**公元前为负数**（公元前 221 年写 `-221`），没有公元 0 年。决定事件在时间轴上的位置、排序、所属时期，以及侧栏“时间范围”筛选的上下限。远古事件可以写很大的负数（约 170 万年前写 `-1700000`）。 |
| `date` | 字符串 | 是 | 卡片和详情中显示的时间文字，可以比 `year` 更灵活，例如 `约前2070年`、`传说时代`、`北宋末年`、`493年起`。在网页中新增事件时若留空，会按年份自动生成（如 `公元前221年`）。 |
| `title` | 字符串 | 是 | 事件名称，不能为空。网页编辑器限制 40 字。维基导入时使用输入的关键词。 |
| `short` | 字符串 | 是 | 简要说明，显示在时间轴卡片上。**至少 20 字（不计标点）**，网页编辑器限制 60 字。不足 20 字时卡片会自动从 `detail` 截取补足，但建议直接写足。 |
| `detail` | 字符串 | 是 | 详细说明，点击卡片后在详情中显示，**不超过 600 字**。可以包含换行。 |
| `images` | 数组 | 是 | 图片，**最多 9 张**，可以为空数组。**第一张为代表图**，按原比例完整显示在时间轴卡片上；其余在详情中以图集显示。没有图片的事件显示首字占位图。每张图片的字段见下表。 |
| `sources` | 数组 | 否 | 参考链接，**最多 10 条**，按顺序显示在详情底部，可以为空数组。每条为 `{ "url": 网址, "title": 标题 }`：`url` 必填，必须以 `http://` 或 `https://` 开头；`title` 可选，没有时维基百科链接显示为“维基百科”，其他链接显示网址。有维基百科链接时详情中附注 CC BY-SA 许可说明。可在网页编辑页添加、修改、删除。维基导入脚本会更新其中同一维基站点的链接。（旧版本的单个链接字段 `source` 已由此字段代替，服务器会拒绝含 `source` 的数据。） |
| `transition` | 对象 | 否 | **时期更迭**：该事件标志着从一个时期进入另一个时期，例如秦统一六国为 `{ "from": "战国", "to": "秦" }`。`from`、`to` 必须是本数据集 `eras` 中的时期名，且不能相同；事件的 `year` 应落在 `to` 时期内（测试会检查）。有此字段的事件在侧栏列表和详情中显示“战国 → 秦”，并可用侧栏的“只看时期更迭的事件”筛选（数据中没有此类事件时不显示该筛选）。不是时期更迭的事件不写这个字段。可在网页编辑页中设置或清除。 |
| `type` | 字符串 | 否 | 事件类型，**必须是本数据集 `types` 列表中的名称**（数据集没有 `types` 时可以是任意文字）。在侧栏列表和详情中以该类型的颜色显示，并可用侧栏的“事件类型”下拉列表筛选；没有类型的事件归为“未分类”。可在网页编辑页修改。 |
| `majorScore` | 整数 | 否 | 重要程度，**1–10 的整数**，缺省视为 5。决定时间轴上代表图的大小，分三级：**1–5 小、6–7 中、8–10 大**；8–10 分即为“重大事件”，标题字号更大，可用侧栏的“只看重大事件”筛选。可在网页编辑页修改。（旧版本的布尔字段 `major` 已由此字段代替，不再使用。） |
| `wiki` | 字符串 | 否 | 对应的维基百科条目名，由维基导入脚本写入，用于再次导入时识别同一事件。网站不使用该字段。 |

### 图片（`images` 中的每一项）

**所有图片都保存在仓库的 `images/` 目录，网站只从本地加载图片，不引用任何外部地址。**

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `src` | 字符串 | 是 | 图片路径，**只能是 `images/<文件名>` 形式**（文件名由字母、数字、`.`、`_`、`-` 组成）。外部网址、`data:` 内嵌图片或其他目录都会被服务器拒绝。新下载或上传的图片以内容的 SHA-256 哈希前 16 位命名（如 `images/1f0e3c9a7b2d4e5f.jpg`），同一张图片只保存一份，可以被多个事件共用。 |
| `w` | 整数 | 建议 | 图片宽度（像素），**必须与文件实际尺寸一致**。时间轴按 `w / h` 预先计算卡片形状，使代表图按原比例完整显示；缺少时网页会在图片加载后测量并重新排版。 |
| `h` | 整数 | 建议 | 图片高度（像素），要求同 `w`。 |
| `caption` | 字符串 | 否 | 图片标题（图注），显示在图片查看器中，可以为空字符串。可在网页编辑页每张图片下方修改，首尾空格会被去掉；本地文件模式下直接写回本文件。 |
| `author` | 字符串 | 否 | 图片作者（不超过 200 字）。不知道时省略。 |
| `license` | 字符串 | 否 | 许可证（不超过 60 字），如 `CC BY-SA 4.0`、`CC BY 3.0`、`CC0`、`Public domain`（公有领域）；知识共享许可证和 CC0 在网站上链接到许可证说明。**`unknown` 表示作者和许可不详**（网上找的图片）。 |
| `sourceUrl` | 字符串 | 否 | 来源网址，以 `http://` 或 `https://` 开头：维基共享资源的文件页（如 `https://commons.wikimedia.org/wiki/File:xxx.jpg`），或图片所在的网页。 |

图片版权（`author`、`license`、`sourceUrl`）：

- 网站在图片查看器中标题下方显示署名，详情页底部列出“图片来源”，事件静态页在图注中显示署名：有许可证时为“图：作者 · 许可证 · 原图”；`license` 为 `unknown` 时，有来源网址显示“图片来源：网站 · 作者与许可不详”，没有则显示“图片来源网络，作者不详”，并附“联系我们”（打开这张图片的反馈）。三项都没有时视为还没有填写，不显示署名。
- 编辑页：添加图片栏下方“这张图的版权”一行填写新图片的版权（粘贴维基共享资源的文件页或 `upload.wikimedia.org` 图片网址时，网页查询维基共享资源后自动填写；新图片的许可证默认为“不详”，来源网址默认为粘贴的网址）；“图片信息”表（默认折叠）中可以修改每张图片的标题和版权。
- 版权与语言无关：同一国家各语言的数据集（如 `cn_zh`、`cn_en`）中，同一张图片的版权应保持一致。编辑页保存时，会把该事件的图片（顺序、尺寸、版权）同步到其他语言数据集中的同一事件，图片标题用“图片信息”表中对照语言一栏的标题（新图片没有填写时为空）；其他语言的数据集中没有这个事件时不同步。

图片格式为 JPEG、PNG、GIF 或 WebP。

## 如何修改数据

- **网页编辑**：在项目目录运行 `npm start`，打开 http://127.0.0.1:4173/ ，在侧栏底部开启“调试模式”（编辑功能只在调试模式下显示）后，在网页中新增、编辑、删除事件会直接写回本文件；上传的图片和通过网址添加的图片都会保存到 `images/`（网址图片由本地服务器下载，数据中只记录本地路径）。
- **从维基百科导入**：`npm run wiki -- --file data/cn_zh.json 关键词`，会查询维基百科、下载图片并新增或更新事件（用法见仓库根目录 README）。
- **手工编辑**：直接修改 JSON 时，新图片需先放入 `images/` 并填写正确的 `w`、`h`。

无论哪种方式，提交前都要运行 `npm test`：测试会检查所有图片都是 `images/` 下存在的文件、尺寸与记录一致，以及排版规则等。

## 服务器保存时的校验

本地服务器（`npm start`）和导入脚本写入前会用同一套规则校验（`server.js` 中的 `validateDataset`），不通过则拒绝写入、原文件保持不变：

- `id` 与文件名一致，`eras` 和 `events` 都是数组；
- 每个事件是对象，`id` 为非空字符串且不重复，`title` 非空，`year` 为数字；
- 若有 `transition`，其 `from`、`to` 必须是 `eras` 中的时期名，且不能相同；
- 若有 `types`，每项的 `name` 不能为空或重复，`color` 为 `#rrggbb`；事件的 `type` 必须是其中的名称；
- 若有 `majorScore`，必须是 1–10 的整数；
- 若有 `music`，`src` 必须是 `audio/` 下的 mp3 / ogg / m4a 文件，`volume` 在 0–1 之间；
- 若有 `texture`，`src` 必须是 `textures/` 下的 svg / png / webp 文件，`size` 在 8–2000 之间，`opacity` 在 0–0.3 之间；
- 若有 `sources`，最多 10 条，每条的 `url` 以 `http://` 或 `https://` 开头、`title` 为文字；不能再使用旧的 `source` 字段；
- `images` 是最多 9 项的数组，每项都有 `src`，且 `src` 必须是 `images/` 下的本地文件路径。
- 图片的 `author` 是不超过 200 字的文字，`license` 是不超过 60 字的非空文字，`sourceUrl` 以 `http://` 或 `https://` 开头。
